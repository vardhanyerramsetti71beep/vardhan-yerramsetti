# Vardhan Yerramsetti — Cinematic Portfolio

A film-inspired personal portfolio: a particle intro video, a movie-poster hero, chapter title cards, a horizontal reel of live projects, a cast-list of skills and rolling end credits.

**Live:** https://vardhan-yerramsetti.vercel.app

## Built with
- HTML, CSS and vanilla JavaScript (no build step)
- [GSAP](https://gsap.com/) + ScrollTrigger for scroll-driven animation
- [Lenis](https://github.com/darkroomengineering/lenis) for smooth scrolling
- Web Audio API for the optional projector sound
- Deployed on Vercel

## Run locally
```bash
python -m http.server 5180
```
Then open http://localhost:5180.
